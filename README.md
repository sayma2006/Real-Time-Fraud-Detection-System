# Real-Time Fraud Detection System

## Overview

A machine-learning based fraud detection system that predicts
whether a credit-card transaction is fraudulent.

## Models

- Logistic Regression
- XGBoost

## Dataset

Credit Card Fraud Detection dataset

284,807 transactions
492 fraud cases

## Technologies

Python
Scikit-learn
XGBoost
FastAPI
Uvicorn
Matplotlib
ngrok

## Features

- Fraud prediction
- Model comparison
- REST API
- Concurrent performance testing
- Inference-time analysis
- Memory usage analysis
